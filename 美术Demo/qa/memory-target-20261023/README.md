实际完成：内存授权关闭 → 原生确认只开内存作用域 → 原生选定工厂内存 Boss → 正常炼气自动攻击及实际格挡 → 一次自然力竭并按正式规则调息恢复 → 击败同一个 Boss → 实际工作集整理 → 原生结果显示 → 原生撤销 → 五主档保存与生产 Load。

真正的工作集 API 仅调用一次，只操作本次创建并持续核对路径、启动时间、SHA、nonce及保留句柄的专用隐藏进程。文件清理、进程退出及无人值守维护始终关闭，没有执行全系统候选回收。正常只读生态采样继续运行；Boss 是显式工厂来源夹具，不是本次自然内存压力触发的证明。

实测工作集125,689,856字节→0，结果显示119.9 MiB；系统内存仍显示约74.0%→74.0%。这是瞬时工作集观测，不是永久释放内存或系统提速承诺。随后专用进程重新读取96 MiB全部24576页的每个字节，完整SHA一致；读取会重新使页面驻留。最后STOP正常退出0。
