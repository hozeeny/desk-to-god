# 《桌面修仙传》可玩美术 Demo

目标：用同一名 M2 修士演示凡人主动战斗、十杀觉醒、炼气自动战斗，并查看筑基洞天。美术方向为国漫仙侠·精致微缩风。

## 运行

Windows x64 / .NET Framework 4.8。无需管理员权限、API Key 或外部图像服务。

首次构建并启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\美术Demo\launch-demo.ps1
```

构建后可直接双击 `美术Demo/runtime/桌面修仙-美术Demo.exe`，或运行 `launch-demo.ps1 -SkipBuild`。

本轮便携交付包为 `美术Demo/桌面修仙-美术Demo.zip`。完整解压后双击其中同名 EXE；请保留旁边两个素材目录。程序和压缩包为本地构建产物，源码、资源和验证记录保存在美术分支。

## 演示操作

1. 进入凡人战斗，点击妖物或「出招」主动攻击，可格挡。冷却与伤害沿用真实玩法。
2. 完成十次有效击杀后点击觉醒，人物切换炼气形态；可开启自动战斗，观察真实击杀与修为变化。
3. 快进只加速本 Demo 的战斗/吐纳时间，不改十杀要求、不直接写击杀数。
4. 可切换镜妖/精英对练阵容；替换阵容不计击杀。
5. 进入明确标注的筑基洞天预置档，查看同人筑基形态及灵田、炼丹等既有设施操作。预置档独立于凡人成长演示，不冒充自然突破成果。

资源栏的道具图鉴只是类别展示，数值栏仅展示当前真实模型数据，不虚构货币余额。

## 隔离与当前表现范围

Demo 为独立命名、独立输出的可执行程序，只用内存模型，退出即重置；不会读取或写入正式存档，不连接网络，不做文件清理或内存回收。双击默认为 Demo，其他正式入口被拒绝。

新资源在 `源代码/ArtDemoAssets`，打包时复制到 Demo 的独立目录；原 `Assets` 不覆盖。正常程序未设置 `DESK_TO_GOD_ART_DEMO_ASSETS` 时继续原渲染路径。

本版角色采用完整插画与呼吸、位移、前倾、握持、受击及消散反馈，保留旧骨骼系统。它是可玩美术纵切，尚未完成新角色的11部件骨骼制作，跑步不是新的逐关节动作。

## 资产与证据

- `asset-inputs.json`：选定资源、源图及机械切片/缩放规则。
- `prompts/` 与 `generated/`：内置 imagegen 的提示词和原始高清结果；候选保留。
- `qa/assets/`：24图联系表、像素/哈希校验及镜妖细节。
- `generation-sources.json`：炼气与筑基 A/B 比较、最终选用依据。
- `support-generation-sources.json`：其他图像的生成来源。

最终构建、玩法和桌面验收结果见本目录的验收记录；未完成的测试不以进程退出码代替可见画面证据。
