# 《桌面修仙传》V6.0｜成长体系与机缘突破（任务B延伸）交付文档

分支：`feature/v6-growth-breakthrough`（基于 PR #3 最新提交 `cbf78e9`，独立 worktree 开发）

本阶段把「凡人十战 → 觉醒灵根 → 炼气十二层 → 寻找机缘 → 筑基突破」做成可执行、可保存、可长期养成的完整闭环，重构第一阶段的境界规则（每境 20 层、第 10 层破境、第 20 层保底），替换为各大境界独立配置的成长体系。不与 PR #1/#2/#3 合并，独立 Draft PR 交付。

## 一、成长闭环

| 阶段 | 规则 |
| --- | --- |
| 凡人期 | 新存档从凡人开始：无灵根、无修仙功法、不能吐纳灵气；战斗照常进行，全部修为收益暂存「灵明」（deferred），累计历练照常记录 |
| 灵根觉醒 | 十次有效妖物击杀（虚拟妖物与未授权虚拟结算均计入，每场独立战斗只计一次，计数封顶 10，幂等）后，修行面板开启「灵根觉醒」仪式：测出先天灵根（金木水火土杂均可摇出），按灵根共鸣赐下初始路线与基础功法，生成道号；暂存灵明一次转化为真实修为 |
| 炼气十二层 | 每层修为需求独立配置（见下表），不是倍数公式；本境圆满后继续获得的修为转化为破境感悟 |
| 破境契机 | 四条路径并行不互斥，任一即可开启破境仪式（详见第三节） |
| 筑基突破 | 功能性破境交互：确认条件 → 查看契机 → 选择材料 → 看清成功率与保底 → 发起 → 结算。失败不损失境界、灵根与修为根基，只追加破境感悟；感悟达到保底阈值后必定成功 |

## 三、破境契机四途径（并行不互斥）

| 契机 | id | 获取方式 |
| --- | --- | --- |
| 天材地宝 | `treasure` | 蜃楼主镜凝出的「水月灵髓」在手（炼气十层以上首胜蜃楼主） |
| 秘境寻宝 | `realm` | 通关千面蜃楼秘境（道途或境界达标后进入） |
| 百业悟道 | `baiye` | 任一后天道途达到 Lv.3，或获得百业传承「天机阵图」 |
| 长期苦修 | `insight` | 本境圆满后持续吐纳，破境感悟满 500 自悟（核心自动领悟） |

契机由控制器在蜃楼结算、百业节拍与修仙核心内分别评估，幂等授予（`opp.<id>=1` 落档）；突破成功后清空，新境界需要重新寻得契机。

## 四、蜃楼筑基机缘「水月灵髓」

- 与真实探索/战斗绑定：炼气十层以上的修士，首次在蜃楼主镜之战获胜，主镜凝出「水月灵髓」×1（材料入灵域收藏）。
- 台账幂等（grant id `mirage-lingsui`）：重复击败蜃楼主只发通关奖励，灵髓不重复凝出；战斗中重启按持久化语义补发战斗后依旧只发一次。
- 凡人不能进入灵域（未觉醒不可绕过成长规则）；传承「水月镜符」获取规则不变。

## 五、境界-战斗强度联动

每拍由控制器同步到战斗模型（`CultivationCombatPower`，纯函数）：

| 状态 | 伤害系数 | 防御系数（受击） | 调息时长系数 |
| --- | --- | --- | --- |
| 凡人 | 0.75（明显偏弱但能推进） | 1.0 | 1.0 |
| 炼气第 N 层 | 1 + N×5%（觉醒即 1.4 倍于凡人，渐强） | 1.0 | 1.0 |
| 筑基及以上第 R 境 | 再 +R×100% 基础实力（大境界真跃迁） | 0.75（灵气护体） | 0.5（恢复加倍） |

炼气中期（第 6 层起）虚拟妖物 30% 概率刷出精英变体：血量 ×2.5、击杀修为 ×2（配置于 `CultivationBalance`）。

## 六、存档与迁移方案

修仙存档 `cultivation-v2.txt` 新增字段：`mortal` / `mkills`（凡人历练计数，落档封顶 10）/ `deferred`（暂存灵明）/ `insight`（破境感悟）/ `opp.<id>=1`（契机）。原子保存 + `.bak` 备份不变。

- **新玩家**：无档案 → 凡人开局（`mortal=1`），`EnsureIdentity` 对凡人直接返回，绝不静默分配灵根。
- **既有 v2 档案**：任何既有存档默认都是修士（`mortal` 缺省 false），灵根、道号、境界原样保留；旧版每境 20 层并入新层数表——超出层数每层折算 100 破境感悟，圆满档结余修为同规则并入感悟（与圆满后收益转感悟同一规则），感悟满 500 自动补记长期苦修契机。
- **v1 实验档案**：照常迁移为第二版，保留层数修为与自动作战默认。
- **损坏/未知版本档案**：档案文件存在但无法读取时，回退为「保留修士身份」的初始档（非凡人），由 `EnsureIdentity` 重新感应灵根——绝不因异常读取把老玩家打回凡人。仅当档案从未存在时才以凡人开局。
- 非法行拒收：超上限击杀计数、畸形契机/机缘键在读取时丢弃。

## 七、界面

- **修行面板**：凡人期显示「凡俗少年 · 凡人 · 红尘历练 N/10」与暂存灵明；历练圆满出现「灵根觉醒」按钮（功能性确认对话框）。觉醒后显示灵根/路线/功法/修为进度/破境感悟；圆满后提示四途径契机状态；「破境仪式」按钮在契机已至时标注。
- **破境仪式窗体**（新）：当前修行卡、四途径契机逐项（已悟得 ✓ / 未得 ○ + 获取途径）、辅助材料勾选（库存与加成实时测算）、成功率拆解（基础 + 感悟加成 + 材料 / 保底必成标注）、失败后果说明、「发起破境」按钮。500ms 自动刷新。

## 十、已知问题与后续建议

- 筑基及以上境界数值为第一版测试参数，未经长时间实机节奏校验；后续纵切按各自主题（百业证道深化、其余三座灵域）调整。
- 精英妖物仅有数值差异，无独立美术标识（复用现有怪物渲染）；后续美术升级时补充。
- 破境仪式为功能性交互（无视觉特效），符合本阶段要求；「桌面破境」表现层在后续阶段开发。
- 旧版战斗熟练等级（Lv.1—100）与修仙境界继续并存展示，面板已注明「战斗熟练等级，与修仙境界相互独立」；统一为单一修仙境界的迁移建议在第一阶段交付文档第六节基础上另行评估，本阶段不动旧战斗系统。
- 真实 GUI 长时间挂机联动（凡人到筑基全流程实机）未在本分支实跑；逻辑层由 GrowthSmoke 覆盖，建议合并前在测试机上做一次实机走查。
