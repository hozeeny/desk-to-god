## 一、设计任务与已确认约束

设计一位从凡人走入炼气、再到筑基的标准修士。三阶段面容核心特征保持一致：凡人朴素、炼气清逸、筑基沉稳，通过服装、姿态和灵气结构呈现成长，不仅更换颜色。具体人物造型尚未定稿，先由凡人候选确定人物身份，以下结构与装束建议供审核和后续延展使用。

2026-10-18 流程调整为：Codex 使用内置 GPT Image/imagegen 生成候选 → 产品审核 → 修改确认 → Codex 制作游戏资产 → 接入与验收，不再等待产品另行供稿。本轮仅生成 A1、A2、A3 三张独立竖版凡人主角原画及 220×240 预览，不拆 12 格、不生成炼气或筑基、不接入游戏或修改渲染代码。产品选定身份后再延展同一人的三阶段。使用内置工具，不切换 CLI；额外付费 API 必须先征得产品同意。

| 已确认约束 | 对设计的要求 |
| --- | --- |
| A｜国漫仙侠·精致微缩风，约 2.8—3 头身 | 高质量 2.5D 体积与微缩可读性并重；布料、玉石、金属各有材质表现，避免廉价玩具感 |
| 桌面角色实际窗口基准为 220×240 像素 | 原画构图要为动作、武器和状态留空间；不能把画布尺寸当作人物净高度 |
| 沿用可拆分的连续骨骼思路 | 四肢有明确连接位置；袖、袍、飘带不能靠整张静态立绘遮住关节问题 |
| 同一角色具有统一识别 | 脸型、发型主轮廓、五官比例与核心服装关系稳定；改变装束不改变人物身份 |
| 需要原画质量与材质层次 | 布、皮、玉、金属从形体和反光上区分；少量有效细节优于全身密纹 |
| 不需要装饰文字 | 角色、分件与透明预览不带标题、英文、数字、印章式伪字或水印；说明文字置于独立文档 |
| 本轮凡人候选 | 三张独立竖版、完整全身及双脚，留动作和武器空间，优先真透明 PNG，无边框；不带灵气光环、华丽武器或高阶饰品 |

右向四分之三视角与统一左上柔光已确认。三张候选和后续选定人物的三阶段应保持同一视角及光向，并在后续接入时检查左向镜像。

现有 `AdventureController.HeroSize` 为 220×240；`AdventureRenderer` 的人物逻辑画布以 220×220 缩放到实际窗口。现有头部与躯干分别有固定绘制尺寸，肢体按骨长拼接，不能用新立绘尺寸推断最终头身比。已确认的 2.8—3 头身必须在后续技术接入中核对，不能直接当作旧骨骼已经支持。

## 二、人物基础提案与待确认项

**讨论起点：年轻、偏中性的普通修士。** 让玩家先看到一个可陪伴、可信且有修行潜力的人，而非已经完成成长的仙尊。此设定用于组织后续描述，不代替产品方的角色选择。

本轮 A1、A2、A3 须在同一体系内形成明显不同的发型、脸部、气质、剪影及配色，不能只换衣服颜色。三张是供选择的不同人物方向，不是同一人的三阶段。下文具体发型、领口和配色仅为结构示例，不要求三张都套用同一人设；产品选中并确认修改后，才固定该人物的识别锚点。候选及审核记录见 [美术候选/凡人主角/round-01-v1](../../美术候选/凡人主角/round-01-v1/README.md)。

| 维度 | 已确认内容或本文设计建议 | 状态与后续要求 |
| --- | --- | --- |
| 性别表达 | 偏中性，不靠浓妆、体态夸张或性别化服装制造记忆点 | 待产品确认；可调整为明确男性、女性或继续中性，三阶段必须一致 |
| 年龄感 | 青年感，约 18—25 岁的视觉区间 | 待产品确认；不在三阶段之间改成儿童→成人→长者 |
| 头身比 | 约 2.8—3 头身，保留脸部可读性，身体结构与动作清楚 | 产品已于 2026-10-18 确认该范围；具体比例以确认稿核对，后续评估骨骼适配 |
| 表情气质 | 凡人朴素、炼气清逸、筑基沉稳；安静专注的表情可作建议 | 三阶段气质已确认；具体表情仍待确认，不靠换眼睛大小或换脸表达境界 |
| 主色关系 | 深色头发，浅内领，偏深外衣；用一个小面积暖色或玉色识别点 | 仅为建议；具体色值和冷暖待产品确认稿明确 |
| 身份背景 | 普通人入道，不预设宗门徽记、特殊血统或唯一职业 | 待产品确认；美术不为角色新增玩法身份 |

产品从候选选定身份并确认修改后，先固定本节与识别锚点，再延展三阶段。不得为省图而让不同阶段采用不同基础人设。

## 三、同一人的稳定识别锚点

以下是**待核准的锚点组合提案**。通过后应在角色设定页固定下来；核准前不视为不可变更的人设。

| 锚点 | 建议形态 | 三阶段稳定项 | 可以成长的部分 |
| --- | --- | --- | --- |
| 脸部轮廓 | 额部与颧部转折清楚，下颌收束不过尖；右向四分之三中保留近侧面颊和远侧眼的关系 | 脸宽、下颌、眼距、鼻口位置和肤色关系 | 神情与目光专注程度；不换脸型、不扩大双眼 |
| 发型轮廓 | 深发高束，额前保留一个可见的斜向发束，后发形成短而清楚的弧线 | 发际线、额前发束方向、束发位置、后脑轮廓 | 布绳→规整束带→小型发冠；顶饰不能遮没核心发型 |
| 领口关系 | 浅色交领形成明确的内侧折线，深外衣包围 | 交领方向、颈部露出与领口层次 | 单层领→分层领→有结构的法衣领；不把领口堆成护甲塔 |
| 腰部识别点 | 一条斜向或错位束带，保留一个小结或小坠 | 在人物自身身体侧的位置与大小等级；不使用文字徽记 | 布结→小玉扣→成套腰扣；不长成大面积金属腰甲 |
| 身体关系 | 头、肩、腰、胯和腿的主比例固定 | 肩宽、躯干长度、四肢长度、近远侧关系 | 服装外轮廓与站姿幅度；不通过增高和变壮表示境界 |

脸与发型至少提供一张三阶段并排的无配饰对照。把三张头部移到同样大小并遮去冠饰，仍应能认作同一人。单侧配件按“近侧/远侧、人物自身左/右”标注；后续镜像会翻转画面方向，不把痣、文字或单侧徽记设为唯一身份凭据。

## 四、凡人、炼气、筑基的可见成长

三阶段气质与同一人原则已确认。本表中的具体服装、配件和灵气形式仍是供产品选择的结构建议，不增加战力、装备槽、职业门槛或获得方式。每个阶段至少有两项不依赖颜色与光效的结构变化。

| 设计维度 | 凡人：朴素 | 炼气：清逸 | 筑基：沉稳 |
| --- | --- | --- | --- |
| 主剪影 | 窄肩、短外衫、收口袖，下摆短，腿部动作清楚 | 肩颈更整齐，袖口有明确层次；外衣延长为分片短袍，保留两腿间隙 | 内收肩部与外展袍摆形成稳定轮廓；前开衩/侧开衩更清楚，飘带成对或成组但数量克制 |
| 服装结构 | 一件常服加内领，布带束腰，护腕简单，鞋靴实用 | 内衫、短外袍、束腰三层；袖口收束，护腕与靴口呼应 | 稳定的法衣领、肩片或叠襟、较长但可分件的外袍；减少零碎悬挂，不采用全身重甲 |
| 材质 | 粗织布为主，少量旧皮革；大褶和使用痕迹适度，不画成贫困滑稽角色 | 更细密布料与较挺外衣形成软硬区别；一处温润小玉件，皮革限于承重部位 | 法衣有连续柔光与清楚折面，内外层反差更明确；玉件与少量暗金属形成重点，不做全身发亮的塑料材质 |
| 配饰 | 发绳、布结与必要束带 | 规整发带、小玉扣；与凡人布结保持位置传承 | 小型发冠/簪与腰扣形成一套，但发型和布结的形状关系仍能追溯 |
| 站姿与重心 | 双脚踏实，略向前认真观察，肩略紧；不能表现为胆怯缩成一团 | 躯干更直，肩松而手势准确，脚步轻但仍落地 | 重心安定、上身舒展，动作先收后发；不默认悬空、不用体型放大表示强大 |
| 常驻灵气 | 无本体灵气；战斗命中特效仍以现有玩法需要为准 | 候选为小范围呼吸式微光或少量聚散点，不能遮脸；静态无光版仍成立 | 候选为较稳定的局部气流或短暂法纹响应；不常驻铺满窗口的巨型法阵 |
| 小尺寸第一读法 | 短衣、布带、收口与实用鞋，像刚踏入历练的人 | 分层交领、分片短袍、整束袖口，像已能吐纳的修士 | 稳定领肩结构、分开长摆、成套小配件，像根基已成的修士 |
| 拆件重点 | 短袖口别遮肘；衣摆不越过腿部关节 | 袍摆分叉与大腿区分；玉扣不跨腰部运动边界 | 长摆与后飘带的前后关系先画清；需要额外可动层时先列技术适配需求 |

三阶段并排时使用相同身高基准、同一观察角度、相同武器或全部空手。先比较纯黑剪影，再比较灰度，最后看色彩和灵气。三个阶段的差别不应来自不同摄影角度、大面积换底色或特效面积。

## 五、原画方向与材质细则

### 5.1 结构与体积要求

- 脸部至少能读出朝向、近远眼关系与下颌；不用细密睫毛或瞳孔纹理承担识别。
- 大衣褶服务于肩、肘、腰、膝的受力；每个转折都能解释布料从哪里垂落，不为填空添加碎皱。
- 领口、近侧手、腰部结点与脚底是重点检查区。袖边不能切进手掌；发尾与飘带不应在缩小后合成一团。
- 玉石、金属的高光不能沿每条边平均描一圈；颜色相近时仍靠明暗形态区分材质。

### 5.2 已确认风格的材质处理

| 设计重点 | 画面要求 | 需特别防止的问题 |
| --- | --- | --- |
| 2.5D 人物体积 | 脸、领口、手和衣褶有清楚明暗转折；边缘轻重随焦点、光向和材质变化 | 大图精细但缩小发糊、全身等粗描边、五官被碎细节淹没 |
| 布料 | 以褶皱受力、层叠和柔暗面表现粗细差别，关键折面在小尺寸仍可见 | 每道衣边都发亮、衣料像塑料、碎皱堆满躯干 |
| 玉石与金属 | 玉石局部温润透亮，金属少而明确的亮暗反差；在同一光源下也能区分 | 所有材质使用相同泛光、全身金边、饰件过量产生廉价玩具感 |
| 精致微缩整体 | 在约 2.8—3 头身中保留面容识别和舒展动作，角色、器物与周边资产保持同一世界 | 用复杂装饰代替原画质量、只靠颜色区分成长、人物与妖物和场景各成一种画风 |

本方案不提前确定最终色值、饰件纹样和具体笔触。上述全局方向已确认，Codex 通过候选呈现具体处理，按产品反馈修改并记录确认版本；生成结果不自动成为定稿。

## 六、220×240 实际显示与动作约束

220×240 是最终检查基准，不是把原画硬缩到恰好撑满的指令。本轮每张凡人候选附该尺寸预览，用于人物选择和小尺寸可读性评审；它不是当前运行渲染链的验收。后续资产制作与接入时须明确 220×220 逻辑画布到窗口的映射，避免在美术端做一次纵向修正、渲染端再拉伸一次。

| 检查项 | 原画与拆件要求 |
| --- | --- |
| 主体占位 | 先固定脚底和人物中心，再确认头顶、衣摆、武器攻击端的活动范围；人物不能为了占满窗口而挤掉动作余量 |
| 细节尺度 | 重要识别结构缩小后应保有可见面积与间距；低于约 2 像素且无法稳定保留的细纹不作为验收依据，优先合并或去除 |
| 动作余量 | 静止、迈步、最大前倾、攻击伸展、转向、调息与复起均检查发饰、袖摆、武器和边缘裁切 |
| 可读性 | 浅、深和复杂桌面都能分离外轮廓；不靠大面积黑描边、外发光或一块不透明底板补救 |
| 脚底与地面 | 鞋底完整、脚踝有可转动结构；支撑脚保持接地，衣摆不掩盖所有脚步；不烘焙固定投影 |
| 界面叠加 | 头顶与脚下不放必须看清的细小装饰；境界、血条、战斗提示由 UI 层绘制，不画进人物 |
| 左右朝向 | 标准源画右向，检查镜像后的手握、武器前端和近远层次；左向光随镜像翻转是当前实现事实，若要求固定世界光需后续单独适配 |

已确认的头身比范围，以及待确认的长袍和更舒展姿态，可能超出现有骨骼假设。不能在文档中承诺它们已经支持，也不能为迁就旧参数把产品确认稿任意压扁；后续制作游戏资产前先列出兼容性差异，当前不修改渲染代码。

## 七、分件方案与各阶段适配

### 7.1 沿用的基础分件语义

现有结构为 4 列×3 行，按行编号。下表是基础对接语义；新资产的尺寸、留白、清单与坐标格式以[角色部件图集与骨骼技术规范](角色部件图集与骨骼技术规范.md)为准。当前 `.rects` 支持自定义来源矩形，但不改变部件编号的含义。

| 编号 | 基础内容 | 各阶段要求 |
| --- | --- | --- |
| 0 | 完整头部，含固定发型与头饰；不含躯干 | 核心脸与发型一致；凡人发绳、炼气束带、筑基小冠均随头运动 |
| 1 | 躯干、腰带及紧随躯干的衣料 | 三阶段均清楚标出领口和腰部；不得把完整手臂、大腿或长摆全部黏在躯干内 |
| 2、4 | 近侧、远侧上臂 | 从肩到肘，向下中立摆放；袖上段与躯干连接处留补绘 |
| 3、5 | 近侧、远侧前臂及握合空手 | 从肘到手；握点明确，不画入武器；宽袖不能吞掉手掌与肘的位置 |
| 6、8 | 近侧、远侧大腿 | 从髋到膝；裤料连续，袍片遮挡关系单独标记 |
| 7、9 | 近侧、远侧小腿及鞋靴 | 从膝到足，右向；膝、踝、鞋底分界可识别，保留脚掌与鞋跟 |
| 10 | 后侧飘带或衣尾 | 当前只有一个基础后摆层；凡人短尾、炼气衣尾、筑基长带的根部都应清楚，不混入人体 |
| 11 | 由同一套部件组成的完整参考 | 空手、标准姿态；不能另画一个更漂亮但无法由分件复现的人物 |

部件不是把成稿沿接缝裁开即可：肩、肘、髋、膝、踝、颈后与衣领下方都需要补画被遮住的形体，保证旋转后没有透明裂缝。补绘量由后续极限姿态决定，不以一组固定像素掩盖所有关节差异。

### 7.2 三阶段拆件差异

| 阶段 | 可沿基础结构交付的内容 | 需先评估的内容 |
| --- | --- | --- |
