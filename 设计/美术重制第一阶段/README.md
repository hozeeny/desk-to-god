# V6.0 美术重制第一阶段

2026-10-18，产品方确认整体美术方向为 **A｜国漫仙侠·精致微缩风**。

高质量 2.5D 国漫仙侠，人物约 2.8—3 头身，强调布料、玉石、金属的材质层次，避免廉价玩具感。同一修士从凡人的朴素、炼气的清逸成长到筑基的沉稳，保持面容与核心识别特征一致，以服装、姿态和灵气的实质变化表达成长。妖物、法器、洞天、秘境及 UI 使用统一视觉体系。

本轮仅在 `desk-to-god-art` / `feature/v6-art-foundation` 推进，新运行素材为 `源代码/ArtDemoAssets`，独立输出在 `美术Demo/runtime`；main、旧 `Assets`、正式版和真实存档不变。完整插画可作呼吸、位移、攻击和受击反馈的纵切，但不声明新角色骨骼分件已经完成。

## 早期分批流程与确认记录（历史）

**2026-10-18 流程调整：Codex 使用内置 GPT Image/imagegen 生成候选 → 产品审核 → 修改确认 → Codex 制作游戏资产 → 接入与验收。** 不再等待产品另行提供原画。性别、年龄感、脸型、发型、配色、配件与最终装束仍由产品通过候选审核确认，候选不自动成为定稿。

本轮先生成 **A1、A2、A3 三张独立竖版凡人主角原画**，分别附 220×240 原尺寸预览。三张在同一视觉体系内保持发型、脸部、气质、剪影和配色的明显差异，供产品选择人物身份；选定后再延展同一人的凡人、炼气、筑基三阶段。本轮不拆 12 格、不生成炼气或筑基、不接入游戏，不替换素材或修改核心渲染代码；JSON 锚点仍是技术提案。

已确认候选约束：右向四分之三视角、统一左上柔光、完整全身及双脚，为动作和武器留空间，优先输出真透明 PNG，无文字、水印、边框；凡人不带灵气光环、华丽武器或高阶饰品。原始 AI PNG 是光栅输出，不能称为分层 PSD；隐藏连接区、独立部件和可编辑分层资料须在确认后另行制作。生成使用内置工具，不切换 CLI；额外付费 API 必须先征得产品同意。

本轮候选目录：[美术候选/凡人主角/round-01-v1](../../美术候选/凡人主角/round-01-v1/README.md)。生成文件、预览与审核状态以该目录记录为准，不提前宣称通过。

**2026-10-18 第二轮进度：** 产品称“图1”的低马尾、侧分碎发、冷静坚定眼神、赭红短交领衣，对应本地上轮 A3-v4；现以该人物方向继续收敛，提供[第二轮 M1/M2/M3 同人小变体](../../美术候选/凡人主角/round-02-directed/README.md)。当前 v2 进一步简化密纹与战斗化护腕，成图仍有细纹，衣料、成熟感及配件取舍待产品审核；方向已用于继续修改，最终造型尚未定稿。本轮不新增 A1/A2/A3 人设、不生成炼气/筑基、不拆图集、不接入游戏，原有技术规范保留。

**2026-10-18 最新确认：** 产品已正式选择 **M2-v2 作为凡人期标准主角基准**，批准其核心设计，仅交付一张当前小幅精修及一张预览；允许简化密纹、加强朴素感，禁止布囊或额外饰品。当前精修 v2 待产品最终确认，仍保留自然细纹；v1 为内部过程稿，不算新增候选。确认后直接基于同一人物设计炼气，不再重选人物。当前不拆件、不集成，原始 PNG 不作为分层源文件或游戏验收通过证据；详见 [M2 正式基准](../../美术候选/凡人主角/M2-正式基准/README.md)。以上早期候选状态保留为历史过程，已锁定项以本次确认为准。
