# V6.0 美术重制第一阶段

2026-10-18，产品方确认整体美术方向为 **A｜国漫仙侠·精致微缩风**。

高质量 2.5D 国漫仙侠，人物约 2.8—3 头身，强调布料、玉石、金属的材质层次，避免廉价玩具感。同一修士从凡人的朴素、炼气的清逸成长到筑基的沉稳，保持面容与核心识别特征一致，以服装、姿态和灵气的实质变化表达成长。妖物、法器、洞天、秘境及 UI 使用统一视觉体系。

**已确认的是整体方向；具体人物造型仍在设计阶段，尚未定稿。** 性别、年龄感、脸型、发型、配色、配件与三阶段最终装束等待产品方确认。后续由产品方提供确认过的设计稿和素材，Codex 负责技术适配。当前不生成新美术图片、不替换素材、不修改核心渲染代码；锚点数据化仅为技术提案。
