# desk to god · 桌面修仙传

Windows 桌面修仙桌宠与网络管理项目。V6.0「持续修仙」基于「骑士助手 v5.4」技术资产开发：桌面修士按真实运行时间持续修炼、巡游、战斗与积累修为，同时保留临时文件清理、网络流量监控、测速及程序网络管理能力。

V6.0 第一阶段加入：道号/灵根/境界/修为/功法的持续修仙体系（炼气至筑基及更高境界的数据结构，每境20层、第10层起可尝试破境、第20层保底）、无临时文件时也会出现虚拟妖物的挂机战斗、独立的第二版修仙存档（原子保存、备份恢复、兼容迁移第一版实验档案）。默认「纯修仙模式」：击败妖物只结算虚拟奖励；真实文件清理与进程工作集回收是两项相互独立的授权，另设默认关闭的「无人值守自动维护」第三授权——未开启时自动作战永不执行真实操作。修士挂机时默认自主作战，力竭后入定调息约一分钟自行恢复，断网不影响本地修炼与战斗。程序默认以普通权限运行，仅网络管理功能需要管理员权限（界面内提供重启提权入口）。

V6.0 第二阶段加入「百业证道」：现实中的工作、学习、创作与娱乐化为八条后天道途（画境/文/游历/阵/天机/器/光影/战）。按前台应用类别识别活动（只读进程名类别，永不读取文档正文、代码、聊天、网页历史与屏幕画面），也可纯手动标记；有效活动时段积累各道途独立道韵与等级，同一时间窗口只结算一种活动，锁屏与长时间无人操作不产生道韵。新增「百业道碑」界面展示道途熟练度、当前活动、获取记录与机缘传承；第一条多道共鸣「阵道 + 天机道 → 天机演算」已实装并预留连续机缘/特殊 NPC/软件秘境的事件结构。识别默认关闭，首次启用有完整说明；百业数据独立存档（baiye-v1.txt），关闭识别立即停止采样，不影响基础挂机修炼。

V6.0 第三阶段加入「软件灵域与机缘」：百业道途化作四座可探索灵域——千面蜃楼（浏览器）、天工机械城（建模）、文曲书院（办公文档）、万象天机楼（AI 工具），识别规则直接复用百业类别定义。进入条件双途径（道途等级或修仙境界），软件未运行也能凭境界进入。首座可玩秘境「千面蜃楼」：渡口/镜廊/雾径/回声壁/中庭节点探索，镜像宝箱、镜妖袭击、幻术迷雾等随机事件，机缘系统（灵根/境界/道途/探索进度门控 + 随机触发 + 玩家选择 + 连续机缘分支），秘境战斗只生成虚拟妖物、绝不触碰真实文件与进程；探索即时存档，支持暂离与中断重访。奖励统一幂等结算：材料/功法残卷/传承入灵域收藏，修为按跨存档协议入账不重发不丢失。灵域数据独立存档（lingyu-v1.txt），本阶段其余三座灵域为数据与接口预留。

V6.0 成长体系延伸（任务B）重构第一阶段境界规则，打通「凡人十战 → 觉醒灵根 → 炼气十二层 → 寻找机缘 → 筑基突破」完整闭环：新玩家从凡人开局（无灵根、收益暂存灵明），十次有效妖物击杀后举行灵根觉醒仪式（六种灵根均可摇出，按灵根共鸣赐功法，暂存收益一次转化）；既有存档永不退回凡人，灵根道号原样保留，旧版每境 20 层并入新层数表（超出层数与圆满结余折算破境感悟）。各大境界层数与突破参数全部独立配置（炼气十二层 120…4300，后续大境界独立数值）；本境圆满后修为转化为破境感悟。破境需握得至少一条契机：天材地宝（蜃楼主镜水月灵髓）/ 秘境寻宝（通关蜃楼）/ 百业悟道（道途 Lv.3 或天机阵图）/ 长期苦修（圆满感悟自悟），四途并行不互斥；失败不损根基、追加感悟，感悟深厚保底必成。新增功能性「破境仪式」界面（条件确认 → 契机查看 → 材料选择 → 成功率拆解 → 发起结算）。境界与战斗强度联动：凡人偏弱、觉醒渐强、筑基获实际能力（灵气护体、恢复加倍），炼气中期起刷出精英妖物。

PR #4 验收整改：① 破境材料安全结算——扣除材料前统一校验状态/圆满/契机/库存，材料消耗按 btmat-<境界>-<序号> 跨存档幂等事务入账（修仙档先行、灵域档随后），启动对账补平崩溃窗口，无资格点击、重复点击、写盘失败、强制退出重启均有回归测试；② 契机按境界分层——契机绑定获得时的大境界（存档格式 v3），各境界独立机缘池并保留苦修保底，筑基机缘不充当结丹资格，新境界须由新的通关/悟道/感悟时刻重新悟得，v2 旧档保守迁移不放大权限；③ 凡人历练防绕过——只有 Strike 真实战斗致死才计历练，一键清场与重复回调不计；④ 境界门槛同步——文曲书院按新版十二层制修正为炼气十二层（圆满），补四座灵域进入条件全矩阵测试；蜃楼镜妖（含主镜 Boss）免疫一键清场，满员时镜妖退休闲置普通妖物腾名额且不突破战场预算。成长节奏模拟：`--growth-sim` 输出档位×功法成长曲线与四机缘难度表，解析模型断言并入 `--selftest`（见设计/V6.0-成长节奏平衡报告.md）。

PR #4 新增整改（凡人主动战斗）：凡人期必须由玩家亲历战斗——自动作战显示「未解锁 · 灵根觉醒后开启」，默认值、控制器初始化、偏好恢复、死亡复活、隐藏/显示、演示与重启路径全部以 AutoBattleUnlocked（=!Mortal）为准，不存在绕过；凡人战斗交互为「点击妖物选定目标 → 角色自动接近 → 进入射程后每次点击出一招（受武器冷却约束）」，点击角色可格挡（1 秒窗口内来袭伤害减至 1/5，10 秒冷却）；凡人力竭仍自动调息恢复，但恢复后保持手动等待玩家操作；十次有效击杀后举行觉醒仪式，进入炼气一层即解锁并默认开启自动作战与自动吐纳，手动点选始终可选；既有修士存档保留其自动作战偏好，不强制退回手动。新增 11 项 Growth 回归测试（凡人锁定、点击出招、格挡冷却、凡人复活保持手动、觉醒解锁、旧档偏好保留）。

## 构建和运行

需要 Windows 10/11 64 位、.NET Framework 4.8 和 PowerShell。构建使用系统自带的 C# 编译器，无需 Python、Node.js 或 NuGet。

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\源代码\build.ps1"
```

程序以普通权限启动（`asInvoker`），修仙、桌面冒险与临时文件功能开箱即用。网络监控、限速和断网需要管理员权限：普通权限运行时主界面底部会出现「以管理员身份重启 · 启用网络管理」按钮，重启后自动接管；也可以右键「以管理员身份运行」直接启动。运行网络管理功能还需要官方 WinDivert 2.2.2 的 x64 库与驱动；仓库已有正式版中的配套文件，可复制到构建输出目录：

```powershell
Copy-Item -LiteralPath ".\正式版\WinDivert.dll", ".\正式版\WinDivert64.sys" -Destination ".\源代码\bin"
Copy-Item -LiteralPath ".\正式版\第三方许可" -Destination ".\源代码\bin" -Recurse -Force
& ".\源代码\bin\骑士助手.exe"
```

完整保留 EXE 旁的 `Assets/`、`骑士助手.exe.config`、WinDivert 文件和第三方许可。详细功能与清理范围见 [使用说明](源代码/使用说明.txt)。

## 验证和打包

构建后，在管理员 PowerShell 中运行内置测试，并检查退出码：

```powershell
$executable = (Resolve-Path ".\源代码\bin\骑士助手.exe").Path
foreach ($mode in @("--selftest", "--adventure-smoke")) {
    $testProcess = Start-Process -FilePath $executable -ArgumentList $mode -Wait -PassThru -NoNewWindow
    if ($testProcess.ExitCode -ne 0) { throw "$mode 失败：$($testProcess.ExitCode)" }
    Write-Host "$mode 通过"
}
```

`--selftest` 使用纯逻辑和隔离文件测试；`--adventure-smoke` 检查合成战斗、屏幕外窗口及自建文件通知测试。其他测试入口和历史结果见 [测试记录](源代码/测试记录.txt)。历史独立审查工具中仍有旧版本路径，单独运行前需调整；日常验证优先使用内置测试入口。

发布前先把当前源码编译到正式版，再打包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\源代码\build.ps1" -OutputDirectory ".\正式版"
powershell -NoProfile -ExecutionPolicy Bypass -File ".\打包发布.ps1"
```

打包脚本以所在仓库目录为根目录，生成 `骑士助手-v5.4.zip` 并核对 ZIP 内容的 SHA-256。版本号变化时需同步调整代码和发布文件名。

## 一起开发

```powershell
git clone https://github.com/hozeeny/desk-to-god.git
cd desk-to-god
git switch -c feature/你的功能名
```

每个功能或修复使用独立分支，通过 Pull Request 合并到 `main`。提交前完成构建和相关验证，PR 中写清修改内容、验证结果，界面变更附截图。开始新任务前先更新本地 `main`。

个人冒险存档在 `%LOCALAPPDATA%/KnightAssistant/adventure-v1.txt`（运行时战斗档，v1 格式不变；首次启动 v6.0 会冻结备份为 `adventure-v1.txt.v54-backup` 供回退 v5.4 使用），修仙存档在 `%LOCALAPPDATA%/KnightAssistant/cultivation-v2.txt`（含 `.bak` 备份），百业道韵存档在 `%LOCALAPPDATA%/KnightAssistant/baiye-v1.txt`（含 `.bak` 备份），灵域历练存档在 `%LOCALAPPDATA%/KnightAssistant/lingyu-v1.txt`（含 `.bak` 备份），真实维护授权（文件清理 / 内存维护 / 无人值守自动维护三项独立）在 `%LOCALAPPDATA%/KnightAssistant/maintenance-consent.txt`，网络记录在 `%LOCALAPPDATA%/NetBunny/`，无需提交到仓库。

WinDivert 的原始许可和源码包随 `正式版/第三方许可/` 保留。项目自身目前尚未指定开源许可证。
